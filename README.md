# 换个技能 · Skill Swap Club

[在线演示](https://highdynamicrange.github.io/selfskill_exchange/) · [个人主页](https://highdynamicrange.github.io/)

以「我能教的 / 我想学的」为起点的技能互换与学习平台原型。

- **用户空间**：本机演示身份、个人技能档案、身份切换、收藏和发布管理。
- **发现课程**：响应式多列封面卡片；按关键词、类别、线上/线下、付费/互换及学习兴趣筛选。
- **发布和详情**：自定义封面链接或图片上传、Description、课程价格、课时设计、试讲方案、成果展示、视频与教案链接；已发布课程可编辑。
- **交换**：保存本机交换邀请。
- **交易演示**：创建订单、模拟付款、老师交付、学员验收、取消、退款、要求补充；记录买卖双方、购买时课程快照和订单历史。

## 体验一次完整交易

1. 默认「学习者」身份打开吉他课程，购买整套课程或预约免费试讲。
2. 勾选演示说明，创建订单，再确认模拟付款。
3. 点击右上角头像，在「我的空间」切换到「周野」。
4. 进入「订单中心 → 我教的课程」，提交交付内容。
5. 切回「学习者」，在「我买的课程」查看交付并确认验收。

**这不是生产支付平台。** 没有真实登录、跨设备同步、消息发送、支付渠道或资金托管。所有演示身份、内容和交易保存在此浏览器的 localStorage；清除站点数据会清除本机内容。演示身份可任意切换，不构成身份认证或数据隔离的安全保障。请勿输入敏感信息或支付凭证。

示例课程、讲师履历、成果与价格均为演示内容。图片可上传 JPG、PNG、WebP（600 KB 以内），视频与教案使用公开链接；MP4 直链可播放，其他视频页面以外链打开。外部素材是否可访问取决于其来源。

## 本地运行

需要 Node.js 22 或更高版本，无第三方运行依赖。

```sh
npm run dev
# http://127.0.0.1:4173
npm run check
```

`npm run check` 执行 JavaScript 语法检查，以及推荐、URL 校验、买卖双方操作权限与订单状态流转测试。

## 部署

`main` 分支推送后由 `.github/workflows/pages.yml` 检查并发布 `site/` 到 GitHub Pages。使用相对资源路径，可直接运行于仓库子路径。

## 目录

- `site/app.js`：用户界面、数据保存、课程与订单交互。
- `site/domain.js`：推荐规则、订单创建与状态转换。
- `site/style.css`：响应式视觉样式。
- `tests/domain.test.js`：核心业务规则测试。
- [产品与后端架构](docs/architecture.md)：真实用户和支付系统的后续设计。
